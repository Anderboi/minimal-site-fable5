# минимал® — сайт студии дизайна интерьера

Одностраничный лендинг (проекты → студия → стоимость → контакты) + отдельная
страница для каждого проекта. Без сборки и зависимостей: чистый HTML/CSS/JS,
анимации на GSAP (ScrollTrigger), плавный скролл на Lenis, WebGL-шейдер света
в hero (без Three.js, чистый WebGL) — всё лежит локально в `assets/vendor/`,
сайту не нужны внешние CDN.

Ключевые приёмы: горизонтальный pinned-скролл проектов (на десктопе),
шлейф картинок за курсором в секции «студия», stacking-карточки тарифов,
аккордеон принципов, побуквенные маски заголовков (Unbounded + Cormorant).

## Запуск

Сайт статический — подойдёт любой хостинг (GitHub Pages, Netlify, Vercel,
обычный nginx). Локально:

```bash
npx serve .
# или
python3 -m http.server 8000
```

и откройте http://localhost:8000. Открывать `index.html` двойным кликом
нельзя: проекты подгружаются `fetch`-ом из JSON, а это не работает с `file://`.

## Как добавить новый проект (без кода)

Все проекты живут в одном файле — **`data/projects.json`**. Сайт сам рисует
карточку на главной, страницу проекта и ссылку «следующий проект».

1. Создайте папку с фотографиями: `assets/img/projects/<slug>/`
   (`slug` — латиницей, без пробелов: `morskoy-briz`).
2. Добавьте объект в массив `projects` в `data/projects.json` (порядок в
   массиве = порядок на главной):

```json
{
  "slug": "morskoy-briz",
  "name": "Морской бриз",
  "type": "Квартира",
  "location": "Калининград, центр",
  "year": "2026",
  "area": "74 м²",
  "duration": "8 месяцев",
  "tagline": "Одно предложение — суть проекта (видно на странице проекта).",
  "task": "Абзац о задаче клиента.",
  "description": [
    "Первый абзац о решении.",
    "Второй абзац.",
    "Третий — по желанию."
  ],
  "facts": [
    { "label": "Комнат", "value": "2" },
    { "label": "Санузлов", "value": "1" }
  ],
  "cover": "assets/img/projects/morskoy-briz/cover.jpg",
  "images": [
    "assets/img/projects/morskoy-briz/01.jpg",
    "assets/img/projects/morskoy-briz/02.jpg"
  ],
  "palette": ["#E8E2D6", "#C9BAA5", "#8F8273", "#3E3A33"]
}
```

3. Готово — обновите страницу.

Подсказки:

- `cover` — вертикальное/горизонтальное фото для карточки и обложки
  (рекомендуем от 1600 px по длинной стороне, формат `.jpg` или `.webp`).
- `images` — любое количество фотографий; первая и каждая третья выводятся
  на всю ширину, остальные — парами.
- `facts` — до четырёх пунктов смотрятся лучше всего.
- `palette` нужна только генератору заглушек, на сайт не влияет —
  для реальных фото её можно не менять.
- Страница проекта доступна по адресу `project.html?p=<slug>`.

## Заглушки вместо фотографий

Сейчас вместо фотографий — сгенерированные SVG-абстракции. Когда появятся
реальные съёмки, просто положите файлы в папку проекта и поправьте пути
`cover`/`images` в JSON. Перегенерировать заглушки (например, для нового
проекта без фото):

```bash
node tools/generate-placeholders.mjs
```

## Структура

```
index.html              — лендинг (hero, проекты, студия, стоимость, контакты)
project.html            — шаблон страницы проекта (?p=slug)
data/projects.json      — ЕДИНСТВЕННЫЙ файл, который нужно править
assets/css/style.css    — стили
assets/js/common.js     — общее: плавный скролл, меню, курсор, загрузка данных
assets/js/main.js       — логика главной (горизонтальный скролл, шлейф, аккордеон)
assets/js/hero-gl.js    — WebGL-шейдер света в hero
assets/js/project.js    — логика страницы проекта
assets/vendor/          — GSAP, ScrollTrigger, Lenis (локально)
assets/fonts/           — Unbounded, Manrope, Cormorant Garamond (self-hosted, кириллица)
tools/                  — генератор SVG-заглушек
```

## Контакты в шаблонах

Почта, телефон и адрес студии прописаны в `index.html` и `project.html`
(секция контактов, мобильное меню, подвал) — замените на реальные.
